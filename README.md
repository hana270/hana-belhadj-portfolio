# Portfolio — Hana Belhadj

Site statique (HTML, CSS, JavaScript), sans étape de build.

## Déployer sur Vercel
1. Remplacez le contenu de votre dépôt par ces fichiers.
2. Importez le dépôt dans Vercel : framework « Other », aucune commande de build, dossier de sortie à la racine.

## Modifier le contenu
Les projets, la stack, le parcours et les certifications sont dans les tableaux `P`, `S`, `T`, `C` en bas de `index.html`.
